# Neon Function Registry

Templates for `neon functions new`. The CLI reads `registry.json` from this folder on `main`.
Point `NEON_FUNCTION_REGISTRY_DIR` at a local checkout to try changes:

```bash
NEON_FUNCTION_REGISTRY_DIR=./registry neon functions new <template>
```

To add or change a template, see [CONTRIBUTING.md](CONTRIBUTING.md).
